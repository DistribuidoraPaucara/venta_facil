PROBLEMA:
  Bug anterior: Dos listeners creaban movimientos simultáneamente
  Resultado: Duplicados en movimientos_caja

SOLUCIÓN:
  Dos comandos Artisan para limpiar de forma segura

═══════════════════════════════════════════════════════════════════════════════

✅ OPCIÓN 1: LIMPIEZA ESTÁNDAR

1️⃣ Primero, VER qué se eliminaría (SIN cambios):
   
   php artisan movimientos:limpiar-duplicados --dry-run

2️⃣ Si el resultado es correcto, ejecutar:
   
   php artisan movimientos:limpiar-duplicados

═══════════════════════════════════════════════════════════════════════════════

🎯 OPCIÓN 2: LIMPIEZA ESTRICTA (RECOMENDADA)

Detecta SOLO duplicados exactos (mismo monto, misma hora)

1️⃣ Ver qué se eliminaría:
   
   php artisan movimientos:limpiar-duplicados-strict --dry-run

2️⃣ Ejecutar (con confirmación):
   
   php artisan movimientos:limpiar-duplicados-strict

3️⃣ (Opcional) Especificar rango de fechas:
   
   php artisan movimientos:limpiar-duplicados-strict --fecha-desde=2026-07-20

═══════════════════════════════════════════════════════════════════════════════

📊 PARÁMETROS ÚTILES

--dry-run           → Simula sin hacer cambios (RECOMENDADO PRIMERO)
--verbose           → Muestra detalles de cada movimiento
--fecha-desde=DATE  → Solo procesa desde esa fecha (STRICT)

EJEMPLOS:
  # Ver detalles sin cambios
  php artisan movimientos:limpiar-duplicados --dry-run --verbose
  
  # Limpiar solo duplicados desde cierta fecha
  php artisan movimientos:limpiar-duplicados-strict --dry-run --fecha-desde=2026-07-24

═══════════════════════════════════════════════════════════════════════════════

🔍 VERIFICACIÓN MANUAL EN BD

Ver duplicados existentes:

  SELECT venta_id, tipo_pago_id, monto, COUNT(*) as cantidad
  FROM movimientos_caja
  WHERE tipo_operacion_id = (
    SELECT id FROM tipo_operacion_caja WHERE codigo='VENTA'
  )
  GROUP BY venta_id, tipo_pago_id, monto, DATE(fecha)
  HAVING COUNT(*) > 1
  ORDER BY cantidad DESC;

🚀 FLUJO RECOMENDADO

1. Hacer backup (por si acaso)
   php artisan backup:run

2. Ver qué se eliminaría (DRY-RUN)
   php artisan movimientos:limpiar-duplicados-strict --dry-run

3. Ejecutar la limpieza
   php artisan movimientos:limpiar-duplicados-strict

4. Verificar en logs que se completó
   tail -30 storage/logs/laravel.log

5. Validar en BD que no hay más duplicados
   (Ver query arriba)

❓ PREGUNTAS FRECUENTES

P: ¿Qué movimiento se mantiene?
R: El más antiguo (menor ID). Los duplicados posteriores se eliminan.

P: ¿Se eliminan datos realmente o solo se marcan?
R: Se eliminan de la BD. Hay auditoría en logs.

P: ¿Puedo deshacer la limpieza?
R: Sí, los IDs eliminados están en los logs. Necesitarías restaurar backup.

P: ¿Qué cantidad de tiempo toma?
R: Depende del volumen. Típicamente: < 1 minuto para 50 duplicados.
